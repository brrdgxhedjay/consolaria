## Overview

Consolaria is a Terraria mod that restores all content that was exclusive to the old console versions of Terraria and later removed — including Ocram and his summoning items, the Turkor the Ungrateful boss, console-exclusive armor sets, and unique drop items — giving PC players access to this removed content that had never been available on the platform.

Whether you're a newcomer just getting started or a seasoned pro looking for advanced tools, **Consolaria** delivers the features you need in a clean, intuitive package.

## Key Features

| Feature | Description |
|---------|-------------|
| **Ocram Boss** | Restored Ocram, the former console-exclusive final boss, with full loot |
| **Turkor Boss** | Restored Turkor the Ungrateful Thanksgiving boss encounter |
| **Console Armor** | Exclusive armor sets from old console versions restored to PC |
| **Exclusive Items** | All console-platform-exclusive weapons and accessories restored |
